# Minimal Markdown

## Overview

When creating or editing any Markdown (`.md`) file, clean typography, compact spacing, and elimination of unnecessary visual clutter are paramount. This skill enforces strict formatting rules to maintain professional, readable, and compact Markdown documentation.

## When to use

- Creating any new Markdown (`.md`) document or runbook.
- Editing, refactoring, or updating existing Markdown files.
- Cleaning up documentation generated by tools or templates that introduce excessive vertical padding.
- Reviewing Markdown files for spacing and whitespace adherence.

## Core concepts

- **Zero Excessive Blank Lines:** Never use more than a single blank line between paragraphs, headers, lists, code blocks, or blockquotes.
- **Trailing Whitespace Elimination:** Strip all trailing whitespace from every line in the file.
- **Frontmatter Compactness:** Keep YAML or TOML frontmatter cleanly formatted with no extraneous padding or empty lines inside or immediately following the delimiters.
- **Compact Block Elements:** Ensure lists, tables, and blockquotes maintain compact spacing without double blank lines between items or rows.

## Practical workflow

1. **Check Spacing During Authoring:**
   - As you write or edit Markdown, review vertical spacing to ensure single blank lines at most.
2. **Review Paragraph and Header Transitions:**
   - Ensure headers (`#`, `##`, etc.) have at most one blank line above and below them (or directly follow frontmatter/parent headers cleanly).
3. **Clean Up Lists and Tables:**
   - Keep bullet points and table rows contiguous without double blank lines separating individual entries unless sub-lists require standard indentation.
4. **Final Whitespace Audit:**
   - Check the file for trailing spaces and multiple consecutive newline characters before saving.

## Common pitfalls

- **Double Blank Lines:** Leaving two or more blank lines between paragraphs or sections out of habit.
- **Trailing Spaces:** Leaving invisible trailing spaces at the end of lines during edits.
- **Frontmatter Padding:** Adding blank lines at the start or end of frontmatter blocks.
- **Uncompacted Lists:** Inserting blank lines between consecutive bullet items in flat lists.
