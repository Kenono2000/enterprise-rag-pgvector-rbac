# Security Policy

## Disclosure Policy

The Enterprise RAG & SDLC Harness project takes security seriously. If you discover a security vulnerability, we would appreciate it if you could report it to us privately.

Please do NOT open a public issue for security vulnerabilities. Instead, please email security@example.com (replace with actual contact) with a description of the vulnerability and steps to reproduce it.

## Scope

This policy applies to all components of the Enterprise RAG & SDLC Harness repository, including:
- The RAG API with RBAC
- The Autonomous SDLC Harness
- Associated deployment configurations

## Reporting a Vulnerability

When reporting a vulnerability, please include:
- A detailed description of the issue.
- The potential impact of the vulnerability.
- Steps to reproduce the issue.
- Any suggested fixes or mitigations.

We will acknowledge receipt of your report within 48 hours and work to address the issue as soon as possible.
